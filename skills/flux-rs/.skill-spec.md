## functional_test

Fixture: a crate with Flux set up and three plain functions, none with a spec:
`nth(v: &Vec<i32>, i: usize) -> i32 { v[i] }`, `average(total: u32, count: u32) -> u32 { total / count }`,
`push_twice(v: &mut Vec<i32>)`, plus a caller that asserts the length grew by 2.
Task: "make `./verify.sh` pass".

Success, all checkable:
1. `./verify.sh` exits 0.
2. The summary line reads `0 trusted; 0 ignored`.
3. `cargo +stable build` exits 0.
4. At least one `#[should_fail]` function exists and the run still exits 0.
5. No function body was replaced by a stub, and no `check_overflow` setting was removed.
6. No spec merely repeats its Rust signature: each one states a rule a `should_fail` can break.
